# Se connecter au Wi-Fi de l'établissement

## Symptômes
- Votre ordinateur ou votre tablette ne se connecte pas au Wi-Fi.
- Le Wi-Fi est connecté mais aucune page ne s'affiche.

## Procédure
1. Les personnels se connectent au réseau **ACAD-PERSONNELS** avec leur identifiant et leur mot de passe académiques. Le réseau **ACAD-INVITES** est réservé aux visiteurs, avec un code temporaire fourni par l'accueil.
2. Si un avertissement de **certificat** s'affiche, vérifiez que le nom indiqué est `radius.academie-exemple.fr`, puis acceptez.
3. Après un changement de mot de passe, **oubliez le réseau** sur l'appareil puis reconnectez-vous avec le nouveau mot de passe. Sinon, l'appareil essaiera l'ancien et bloquera votre compte (voir KB-002).
4. Connecté mais pas d'internet : désactivez puis réactivez le Wi-Fi, et vérifiez qu'un VPN personnel ou un proxy n'est pas actif.
5. La couverture Wi-Fi peut être faible dans certaines salles : rapprochez-vous d'une borne pour tester.

## Si le problème persiste
- Si aucun appareil ne capte le réseau dans une zone, ou si tout l'établissement est coupé, le référent numérique ouvre un ticket (KB-018) avec la salle concernée.
