# Session Windows : profil temporaire ou bureau vide

## Symptômes
- À l'ouverture de session, le message « Vous êtes connecté avec un profil temporaire » s'affiche.
- Votre bureau est vide et vos fichiers semblent avoir disparu.

## Procédure
1. **Pas de panique** : vos fichiers ne sont en général pas supprimés. Windows n'a simplement pas réussi à charger votre profil habituel.
2. **N'enregistrez aucun document** dans cette session : tout ce qui est enregistré dans un profil temporaire est perdu à la déconnexion.
3. Fermez la session, **redémarrez** complètement l'ordinateur, puis reconnectez-vous. Cela suffit dans la majorité des cas.
4. Vérifiez que le poste est bien branché au réseau (câble ou Wi-Fi) avant d'ouvrir la session : certains profils sont chargés depuis le serveur.

## Si le problème persiste
- Si le profil temporaire revient après deux redémarrages, ouvrez un ticket (KB-018) en indiquant le numéro d'inventaire du poste et votre identifiant. La réparation du profil est faite par le niveau 2.
- En attendant, vous pouvez utiliser un autre poste : vos documents enregistrés sur le lecteur réseau restent accessibles (voir KB-019).
