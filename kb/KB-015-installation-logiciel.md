# Demander l'installation d'un logiciel

## Symptômes
- Vous avez besoin d'un logiciel qui n'est pas sur votre poste.
- L'installation vous demande un mot de passe administrateur.

## Procédure
1. Les utilisateurs n'ont pas de droits administrateur sur les postes professionnels, pour des raisons de sécurité.
2. Consultez d'abord le **Centre logiciel** (menu Démarrer > Centre logiciel) : les logiciels du catalogue validé (suite bureautique, lecteur PDF, navigateurs, logiciels pédagogiques courants) s'y installent en un clic, sans droits particuliers.
3. Si le logiciel n'est pas au catalogue, faites une demande sur le portail d'assistance (KB-018), catégorie **Demande de logiciel**. Indiquez :
   - le nom exact et l'éditeur du logiciel ;
   - l'usage prévu (pédagogique ou administratif) ;
   - le nombre de postes concernés.
4. La demande est validée par le référent numérique ou le chef d'établissement, puis étudiée par le support (licence, sécurité, compatibilité). Comptez **5 à 10 jours ouvrés**.

## Si le problème persiste
- Les logiciels gratuits téléchargés sur internet ne sont pas installés sans validation, même s'ils sont gratuits.
