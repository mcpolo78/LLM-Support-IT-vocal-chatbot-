# Accès distant par VPN

## Symptômes
- Vous êtes en télétravail et devez accéder aux applications de gestion internes.
- Le client VPN refuse la connexion ou se déconnecte.

## Procédure
1. L'accès VPN est réservé aux personnels qui en ont besoin (services administratifs, direction). Il doit être **demandé par votre chef de service** via le portail d'assistance.
2. Une fois l'accès ouvert, installez le client VPN depuis https://portail.academie-exemple.fr, rubrique **Outils > Accès distant**. Sur un poste professionnel, il est généralement déjà installé.
3. Lancez le client, saisissez l'adresse `vpn.academie-exemple.fr`, votre identifiant et votre mot de passe académiques, puis le **code d'authentification forte** (voir KB-007).
4. Vérifiez que votre connexion internet fonctionne avant de lancer le VPN. Certains réseaux publics (hôtels, gares) bloquent les VPN.

## Si le problème persiste
- Erreur « utilisateur non autorisé » : votre accès n'est pas encore ouvert. Vérifiez avec votre chef de service que la demande a été faite.
- Erreur de code : vérifiez l'heure de votre téléphone (elle doit être automatique) et reportez-vous à KB-007.
- Déconnexions répétées : notez l'heure et le message d'erreur, puis ouvrez un ticket (KB-018). Ce type d'incident est traité par le niveau 2.
