# Imprimante réseau : ajouter une imprimante ou débloquer une impression

## Symptômes
- L'imprimante n'apparaît pas dans la liste.
- Le document reste dans la file d'attente et ne sort pas.

## Procédure
1. **Ajouter une imprimante** (poste professionnel Windows) : ouvrez l'**Explorateur de fichiers**, tapez `\\impression` dans la barre d'adresse, puis double-cliquez sur l'imprimante voulue. Le nom de l'imprimante est collé sur le copieur (par exemple `COP-SALLE-PROFS`).
2. **Impression bloquée** :
   - vérifiez sur l'écran du copieur qu'il n'y a ni bourrage papier, ni bac vide, ni toner épuisé ;
   - ouvrez **Paramètres > Imprimantes**, cliquez sur l'imprimante puis **Ouvrir la file d'attente**, et annulez les documents en erreur ;
   - relancez l'impression.
3. **Impression sécurisée** : sur certains copieurs, les documents ne sortent qu'après badge ou saisie de votre code sur le copieur.
4. Si l'imprimante affiche « hors connexion », vérifiez qu'elle est allumée et que son câble réseau est branché.

## Si le problème persiste
- Bourrage récurrent, panne mécanique ou toner : contactez le gestionnaire du parc dans l'établissement, qui appelle le prestataire de maintenance.
- Imprimante injoignable pour tous les postes : ouvrez un ticket (KB-018) avec le nom de l'imprimante.
