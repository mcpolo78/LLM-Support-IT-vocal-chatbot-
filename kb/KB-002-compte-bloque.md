# Compte bloqué après plusieurs tentatives de connexion

## Symptômes
- Message « Votre compte est temporairement verrouillé ».
- Le compte se bloque à nouveau peu après chaque déblocage.

## Procédure
1. Après 5 tentatives échouées, le compte est verrouillé **30 minutes**. Le déblocage est automatique : attendez la fin de ce délai.
2. Si vous avez oublié votre mot de passe, ne retentez pas au hasard : utilisez la procédure KB-001.
3. Si le compte se rebloque tout seul, un appareil utilise encore votre **ancien mot de passe**. Vérifiez :
   - la messagerie configurée sur votre smartphone ou tablette (voir KB-004) ;
   - le Wi-Fi de l'établissement enregistré sur vos appareils (voir KB-011) ;
   - le client VPN avec identifiants mémorisés (voir KB-006).
   Mettez à jour le mot de passe sur chaque appareil, ou supprimez puis recréez la connexion.

## Si le problème persiste
- Si le compte reste bloqué plus d'une heure, ou apparaît comme **désactivé**, ouvrez un ticket (KB-018). Un compte désactivé peut correspondre à une fin de contrat ou une mutation non encore enregistrée : le support vérifiera votre situation administrative.
