# Authentification forte et changement de téléphone

## Symptômes
- On vous demande un code à 6 chiffres pour vous connecter.
- Vous avez changé de téléphone, perdu votre téléphone, ou le code est refusé.

## Procédure
1. L'authentification forte ajoute un code à usage unique, généré par une application d'authentification (par exemple FreeOTP, Google Authenticator ou Microsoft Authenticator), à votre mot de passe.
2. **Première activation** : sur le portail, rubrique **Sécurité > Authentification forte**, scannez le QR code avec l'application, puis saisissez le code affiché pour confirmer.
3. **Changement de téléphone** (ancien téléphone encore disponible) : connectez-vous au portail avec l'ancien téléphone, supprimez l'appareil enregistré, puis enregistrez le nouveau en scannant un nouveau QR code.
4. **Code refusé** : le code change toutes les 30 secondes. Vérifiez que l'heure du téléphone est réglée en automatique.

## Si le problème persiste
- **Téléphone perdu ou volé, ou ancien téléphone indisponible** : vous ne pouvez pas réinitialiser seul. Ouvrez un ticket depuis un collègue ou appelez l'assistance (KB-018). Après vérification de votre identité, le support supprime l'ancien appareil et vous pourrez en enregistrer un nouveau. En cas de vol d'un appareil professionnel, voir aussi KB-017.
